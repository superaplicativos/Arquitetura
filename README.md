# Guilherme Miranda - Site Profissional

Site profissional desenvolvido do zero com HTML5, CSS3 e JavaScript puro.

## 🚀 Características

- ✅ **100% Responsivo** - Funciona perfeitamente em todos os dispositivos
- ✅ **Sem Scroll Horizontal** - Design otimizado para evitar scroll lateral
- ✅ **Performance Otimizada** - Carregamento rápido e eficiente
- ✅ **Design Moderno** - Interface limpa e profissional
- ✅ **SEO Friendly** - Estrutura otimizada para mecanismos de busca
- ✅ **Animações Suaves** - Transições e efeitos visuais elegantes

## 📱 Seções do Site

1. **Hero** - Apresentação principal com foto e CTAs
2. **Sobre** - Experiência e estatísticas
3. **Serviços** - 6 serviços principais oferecidos
4. **Cursos** - 4 cursos online disponíveis
5. **Parceiros** - Logos de empresas atendidas
6. **Contato** - Informações de contato e WhatsApp

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (ES6+)
- Google Fonts (Inter)

## 🌐 Deploy

Para fazer deploy no GitHub Pages:

1. Copie todos os arquivos para o repositório
2. Ative o GitHub Pages nas configurações
3. Selecione a branch main como fonte
4. O site estará disponível em: https://superaplicativos.github.io/GuilhermeMiranda
